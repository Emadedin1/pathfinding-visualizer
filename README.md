# Pathfinding Visualizer

An interactive pathfinding visualizer built with React, TypeScript, and Vite.  
The app demonstrates how different pathfinding algorithms explore a grid and find paths in real time.

LIVE DEMO: https://pathfinding-visualizer-q2bdsnnb0-emadedin1s-projects.vercel.app/

## Features

- Interactive grid-based pathfinding visualization
- Start and target nodes
- Wall and weighted nodes
- Click and drag to draw walls or weights
- Right-click to erase walls or weights
- Maze/pattern generation
- Animated traversal and shortest-path discovery

## Algorithms

- Breadth-First Search
- Depth-First Search
- Dijkstra’s Algorithm
- A* Search
- Greedy Best-First Search
